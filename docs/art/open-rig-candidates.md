# Open rig candidates

The production Pokémon sculptures remain static until a candidate's actual
source rig, license and renderer compatibility are inspected and integrated.
A downloadable flag or an animation count does not prove the presence or
absence of a usable skeleton.

[Eleanie's Jigglypuff](https://sketchfab.com/3d-models/jigglypuff-371fa15534b84b9d8975e41627662783)
advertises CC Attribution and an Auto-Rig Pro rig with expressions and a squish
control. The official download API returned HTTP 401 and Chrome's Download
button displayed a login modal. Its source remains inaccessible in this
session. See the separate Jigglypuff sculpture notes for the existing review.

[Eleanie's Pikachu](https://www.blendkit.com/asset-gallery-detail/0eb51b35-d90d-40a9-a2d5-dcb28f574de7/)
advertises full rig controls, expression levers and EEVEE-specific shaders.
The page reports 5,063 polygons and a 4.4 MiB file, with a Royalty Free license.
The [license explanation](https://www.blendkit.com/docs/licenses/) allows
commercial derivative works but restricts resale of models, including modified
models. This does not by itself establish permission to publish the raw asset
in this source repository. The published [download instructions](https://www.blendkit.com/get-blendkit/0eb51b35-d90d-40a9-a2d5-dcb28f574de7/)
require an account and the Blendkit add-on. No asset or add-on was downloaded,
and no account was created. Source accessibility, redistribution terms,
expression export and runtime compatibility remain unverified.

[Eleanie's Sketchfab Pikachu](https://sketchfab.com/3d-models/pikachu-35716003a1964704b1b145e6c6a05b07)
is a separate listing under CC Attribution. The artist advertises Auto-Rig Pro
controls and expression variants. Official metadata reports a downloadable
asset and one animation, but the source download endpoint returned HTTP 401.
This listing offers a different published license from the Blendkit edition;
the source geometry, skeleton, expressions and runtime compatibility remain
uninspected. No external geometry was imported.

[EmblemSauce's Magnemite](https://emblemsauce.itch.io/3d-rigged-pokemon-model)
advertises a downloadable rig. Its published terms allow educational and
portfolio use and prohibit commercial use; raw game-asset redistribution in
this repository is not established. No asset was imported. The original
Magnemite and Magneton sculptures and their mechanical geometry checks are
documented separately.

[LaxminarayanArtistry's animated character pack](https://sketchfab.com/3d-models/low-poly-animated-pokemon-cartoon-character-pack-096fd912250e44d388bf7f3fb49c3a7a)
advertises Mixamo animations and includes Hypno. The official model API reports
a downloadable asset, one animation and CC Attribution licensing. Its download
endpoint returned HTTP 401. The source armature, asset provenance, actual export
and renderer compatibility have not been inspected, so this remains a candidate
rather than an integrated rig. No external geometry was imported.

[06wj's public Pokémon viewer](https://github.com/06wj/pokemon)
ships 151 models with skeletal animations, but its asset credits explicitly
state that the repository grants no rights to the Pokémon assets. Its MIT code
license does not establish reusable asset rights. No geometry was imported.

These are research candidates, not imported or approved assets. Original
sculpture work and the full 251-species visual review continue while a usable
open source rig remains unverified.
