# Mississippi riverbank adventures

Both existing winding 64×68 reaches retain their native dimensions, mouths, reciprocal connections, original water course, encounters and four original trainers. Each reach adds eighteen trainers for **twenty total**, ten substantial grassy landings, six woodland walking links, three once-only supplies and one free field medic. Trainer teams use native level-up moves at levels29–34; the native class controls battle money and defeated flags prevent repeat rewards. The added trainers face inland so ordinary Surf travel does not force every bank battle.

The lower reach has a willow/reed approach, northern meadow and eagle bank, an east-bank stop and a southern oxbow walk. The upstream reach has a southern reed trail and cedar stop, an eastern quiet pool, a pine-tongue walk and a northern lookout. Grass occupies the actual banks and paths. Supply pickups require walking through grass; the main river remains available for direct travel.

## Authoritative source

- `MnMississippiLowerWoods.layout.json` and `MnMississippiUpstreamWoods.layout.json` are complete explicit source rasters, in metatiles.
- `revision.json` contains exact native block preimages/deltas, trainer parties, directions, dialogue, pickups, medic scripts and local gameplay coordinates.
- The parent is `content-packs/minnesota-park-pond-v05.crystalpack`. Its river terrain exactly matches the accepted long-river revision. Historical Mississippi manifests and frozen revisions remain unchanged.
- No map dimensions, endpoint ports, rooms, story gates, or world/interior allocations change. This is a new versioned river authoring stage.

## Build and review

The Rust publisher verifies the exact parent identity, terrain preimages, preserved original water and outer boundary, native programs and resulting pack. It publishes to a fresh ignored output and verifies readback.

```sh
CARGO_TARGET_DIR=target/river-fun cargo build --locked --profile wasm-dev \
  -p crystal-assets --bin build_river_route_fun
target/river-fun/wasm-dev/build_river_route_fun \
  content-packs/minnesota-park-pond-v05.crystalpack \
  planning/minnesota/connections/mississippi-fun-v01/revision.json \
  content-packs/minnesota-mississippi-fun-v02.crystalpack

.local/minnesota-review-env/bin/python planning/minnesota/tools/review_river_fun.py \
  --written content-packs/minnesota-mississippi-fun-v02.crystalpack \
  --output planning/minnesota/renders/river-fun-v01/written-review-next
```

Every review needs a fresh output directory. Whole maps, native cameras, prior passes, controller saves and verification output remain under the ignored `planning/minnesota/renders/river-fun-v01/` tree. The static review compares the complete written residual game data, audio/runtime assets and report; proves both water components, fixed outer boundaries, reachable bank activities and grass-required supplies; and exports exact controller Foot courses. Native fixture tests separately exercise real Surf launch/dismount, each new battle and selected Surf PP/XP/money, pickups, healing, Save/Continue and once-only rewards. Initial Mew level 80/badges/position are declared test setup, not earned campaign progression.
