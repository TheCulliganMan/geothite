# Iron workings sources

`network.json` defines the retained pressure circuits and reciprocal shaft
connections. The three original room files are campaign seed layouts.

The current haulage floor uses the
[native rock galleries](../../caves/iron-haulage-rock-v01/README.md), with a
separate terrain source, Rust publisher and verified native review. The old
warehouse seed alone does not reproduce that floor. Resolve the active
`world.json` revision and source index before publishing further changes.

The current sump uses the
[flooded native rock drift](../../caves/iron-sump-basin-v01/README.md).
Its five shaft pairs, original two-circuit gate and guards remain intact;
optional fishing, Surf, rock boundaries and Continue have production-input
coverage. The old sump seed does not reproduce that terrain.

The current ventilation floor uses the
[native shelf, fin loop and service cleft](../../caves/iron-ventilation-cleft-v01/README.md).
Its original valve and four shaft pairs retain production behavior. The
[three-floor overview](../../renders/iron-ventilation-v534/connected-floors-v557/connected-native-floors-original.png)
labels all eight original network pairs at one native scale. Matching letters
represent actual warps between floors; the drawing does not invent walking seams.

The pump floor now uses the
[native maintenance gallery](../../caves/iron-pump-gallery-v01/README.md),
with two original guard approaches, native climbs, feed-operated core access
and a shorter service return. The
[four-floor overview](../../renders/iron-pump-gallery-v561/four-floors-v594/connected-native-floors-original.png)
adds the actual pump floor and retained drill-core shaft. Its nine lettered
connections are warp pairs at one native scale. The drill-core room still
needs its own quality work.
