# Pepivern: three wakes

This optional discovery uses the existing Lower Woods river, independently of
Verdigrim's Boundary Intake excavation. It never advances or gates the main
story. Its scripts and guarded Rust publisher are implemented in the isolated
review source; they are not compiled, installed, selected or accepted yet.

The shoreline observer records the sketch only after its last page is
acknowledged. A dry-land eddy read and a separate Surf-only shoreline read add
two different observations. The working boat operator compares all three,
then identifies an optional still inlet. Only acknowledgment records that
identification. The player can decline the encounter and keep the quest result.

The encounter uses native optional-legendary battle behavior. Only actual
capture marks caught. RUN or knockout withdraws Pepivern for the visit;
Continue must preserve that withdrawal, while physical map reentry restores an
uncaught encounter. Actual party/selected-PC delivery, all-storage-full refusal,
blackout recovery, reentry and once-only capture still need controller proof.

`site.json` binds five inspected native collision anchors on three existing
river chunks. A read-only flood check found all five approaches in the same
3,710-tile component when Surf is available, accounting for existing actors
and the proposed two people. This is structural evidence, not an earned trip.
The reviewed full-map source images were inspected. No terrain, connection,
original actor, fishing encounter, trainer, grass or existing script is removed.
There are no added signs, tables, campfires, buoys, custom tiles or new maps.

The Surf observation is bound to an existing solid bank at (50,20), read from
water (49,20); a separate dry approach at (50,19) exercises refusal. A walkable
read target would have dismounted the player before checking Surf and was
rejected during source review. All five approaches remain connected.

Three production-controller cases are authored and queued: land observation
acknowledgment/Continue; real Surf launch, land refusal and operator comparison;
and refusal, actual RUN, hidden Continue, physical seam return and actual capture.
They have not run yet. The independent preservation auditor also remains unrun
until a real candidate exists; its own syntax check passes.

The publisher checks canonical coordinates, original species/Dex membership,
native walking art, unoccupied approaches and exact floor/water collision.
It installs only each map's reachable script graph, avoiding unused encounter
definitions on clue-only maps, and parses the real scripted wild battle.
Its CLI requires a fresh ignored output and verifies serialized readback.

Before acceptance: compile and lint the new Rust leaves; independently audit
all unrelated payloads; exercise land/Surf clue acknowledgment and Continue;
walk the actual river, refuse/capture/escape/lose/retry using native input;
inspect the reached production 2D scene; verify all original audio; then
compose with every other accepted stage and run the earned campaign.
