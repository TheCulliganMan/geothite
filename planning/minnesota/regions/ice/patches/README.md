## Checks and native handoff

The source model finds12 ICE core tiles/four legal entry courses in R17 and
eight ICE core tiles/twelve entries in R11. Every legal entry ends on an
unoccupied Floor or existing encounter-grass stop. The old ordinary traversable
footprint and complete grass footprint remain exact; all old non-Floor
collisions, water, ledges, gates, warp quadrants and outer boundaries stay exact.
No new ICE cell touches water. Source bodies and original gameplay fields are
unchanged. Nine negatives reject out-of-bounds cells, moved actors, grass loss,
ICE extending through a dry stop and the rejected pine-wall opening. Eight
all-time prefix comparisons preserve all60/131 original block images.

This is a static directional slide model using native ICE semantics from
`crystal-core/src/world/session.rs::forced_movement_direction`; it is not an
executed native controller. The current ordinary route revision API cannot
swap a private tileset alias. Root needs a bounded additive art/terrain overlay
that preserves old cached and split program representations without reparsing
unrelated scripts. The contract pins exact old modules and permits only the
two alias attributes,15 declared terrain cells/owned block payloads and new
art assets/catalog entries, plus derived identity. No new map/flag/spawn/item/
trainer/quest namespace is allocated.

Actual acceptance should use the contract's16 `(from,direction,ice_path,stop)`
fixtures through production input: turn first if necessary, move onto ICE,
observe forced multi-cell movement, exact stop, legal reverse/exit, no menu/
warp/battle leakage and no input steering before the native stop. Use explicit
initial empty-party placement only for the local geometry fixture; preserve
real populated grass/encounter/resource journeys separately. Verify the old
R11 item remains reachable from48,33 with its original reward/event/once flow,
then Start/Save+Continue on a dry stop and revisit the opposite approach.
Never claim an ICE-midpoint standing source pose as a controller-earned stop.

Carry native prefix water/grass animation behavior onto the aliases. Icy grass
also needs its actual walking-rustle palette checked; the ordinary native
rustle loader uses NPC palette6 independently from the terrain. Source static
grass color does not prove that moving rustle is icy. Preserve the existing Cut/
Headbutt rules if any native field action in a retargeted chunk depends on them.
All of those runtime checks remain Root's integration work.
