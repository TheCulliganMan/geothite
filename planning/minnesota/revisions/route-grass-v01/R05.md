# R05: Route45 grass climbs and dry drops

R05 is accepted in its named review pack; subsequent routes remain separate work. The actual Crystal Route45 source
render was inspected: cliff lanes, bounded grass on useful approaches and
separate one-way downhill paths are the reference. R05 retains its two existing
native south-facing drops, all four ramps and the two-ended rock cut.

## Outdoor direction contract

Thirty-three explicit native grass remaps increase habitat from 19 to 52
metatiles (76 to 208 walking tiles). Five authored areas cover the lower western
climb, upper western climb/old grass connection, sunny meadow extension and
southern shelf. Additional narrow grass necks below the ramps close the dry
bypass exposed by actual walkable cliff-edge quadrants. Both actors and the
pier/Surf launch footing stay unchanged.

The 0/1 directed walking graph proves seven grass steps on the upper outdoor
climb and six on the lower. Each southbound ledge return crosses zero grass in
its corresponding band. Three adversarial variants are rejected: restoring a
dry uphill passage, flattening the reverse ledge face, or grassing the declared
dry return. Static proof:
`planning/minnesota/renders/route-grass-v01/r05-directional-static-eb1292d414a70f43.json`.

This contract covers ordinary outdoor walking. The original two-ended cave
remains a separate alternate route and native healing service; it is not
silently counted as an uphill outdoor grass path.

## Installed source reconciliation

The installed review lineage differs from canonical source at 27 unrelated
metatiles: existing river/seam fitting and the typed southern approach. Every
cell edited by this pass matched the installed preimage. Publication uses exact
native snapshots under `.local/route-grass-review/MN_R05.installed-*`, retains
actual room rows and sign anchors, and freezes the installed typed river-art
suffix as explicit source recipes. No art, water geometry, events or room is
republished. Canonical source snapshots are retained in `before/`.

R05's exact native snapshot needs explicit source-edge fitting so the publisher
does not refit unchanged shore cells. The layout reader now accepts that mode
for R05, as it already does for other native-preservation routes. The revision
checker also now matches the native builder's passive FLOOR return convention:
the passive destination is 1 even when the active entrance uses cave exit 2.
The existing cave records were correct; no schema or warp record changes.

The older standalone source validator rejects any perimeter water, including
existing connected river water. That strict historical check is not evidence
of a changed boundary in this pass. The named pack must pass native connection,
preservation and Surf controller checks before acceptance.
