# UI fidelity checks

Run from the repository root. The browser runners use workspace Playwright, headed Chromium,
a clean browser context, and an 800 × 800 viewport. They exercise controls and
save PNGs plus observed state to `output/ui-fidelity/` for visual inspection.

Serve the built web application at `http://localhost:8091`, with the
`realtime-clock.browser.crystalpack` generated by the web server. Use that exact
pack for the native fixture tests so the saved modpack identity matches.

```sh
export CRYSTAL_RENDER_TEST_PACK="$PWD/output/ui-fidelity/realtime-clock.browser.crystalpack"
export POKEGEAR_PC_RENDER_DIR="$PWD/output/ui-fidelity"
export POKEDEX_RENDER_DIR="$PWD/output/ui-fidelity"
cargo test -p crystal-bevy --lib -- pokegear_start_menu_confirmation_must_be_released_before_clock_exit integrated_pokecenter_pc_opens_from_collision mart_counter_interaction elm_robbery_call_runs_after_overworld_step_without_a pokedex_defaults_to_source_new_order_and_stops_at_last_seen battle_browser_fixture_starts_from_overworld_interaction --test-threads=2
node tools/pokegear-browser-test.mjs
node tools/ui-fidelity-browser.mjs pc
node tools/ui-fidelity-browser.mjs mart
node tools/ui-fidelity-browser.mjs elm
node tools/ui-fidelity-browser.mjs pokedex
node tools/ui-fidelity-browser.mjs battle
```

The battle fixture starts in the overworld and interacts with the tree. It uses
an owned level-100 Pokémon to make the finishing attack reproducible. The battle
runner checks faint narration, script completion, and restored movement. Add
`--display-only` to inspect the entry display without exercising the turn.

Native frame checks and captures:

```sh
cargo test -p crystal-bevy --lib -- battle_sliding_intro_ final_wild_attack_retains_move_and_faint_presentation_before_rewards pokedex_visible_data_respects_ownership_and_formats_dimensions --test-threads=2
```

Inspect the generated images in addition to the assertions. Semantic text checks
alone cannot detect compositor scaling, occluded terrain, or stale sprites.
